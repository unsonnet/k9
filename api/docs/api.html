    API Reference

    Auth API

    POST /auth/forget

    Request password reset for user account.

    Request

    Body (application/json)

    username string required
    User name

    Responses

    No content — password reset link sent to admin

    Bad request — invalid request payload (InvalidRequest)

    Not found — user does not exist (NotFound)

    Internal server error (InternalServerError)

    POST /auth/login

    Authenticate user with username and password.

    Request

    Body (application/json)

    username string required
    User name
    password string required
    User password

    Responses

    OK — user logged in

    Body (application/json)

    user string required
    User ID (UUID)
    accessToken string required
    JWT access token
    refreshToken string required
    JWT refresh token
    expiresIn integer required
    Access token expiry (seconds)

    Accepted — new password required

    Body (application/json)

    username string required
    User name
    challenge string required
    Challenge type (NEW_PASSWORD_REQUIRED)
    session string required
    Session token for challenge response

    Bad request — invalid request payload (InvalidRequest)

    Unauthorized — invalid credentials (Unauthorized)

    Not found — user does not exist (NotFound)

    Internal server error (InternalServerError)

    POST /auth/logout

    Logout user and invalidate tokens.

    Request

    Headers

    Authorization string required
    Bearer JWT access token

    Responses

    No content — user logged out

    Unauthorized — missing or invalid Authorization header (Unauthorized)

    Internal server error (InternalServerError)

    POST /auth/refresh

    Refresh access token using refresh token.

    Request

    Body (application/json)

    username string required
    User name
    refreshToken string required
    JWT refresh token

    Responses

    OK — token refreshed

    Body (application/json)

    user string required
    User ID (UUID)
    accessToken string required
    JWT access token
    refreshToken string required
    JWT refresh token
    expiresIn integer required
    Access token expiry (seconds)

    Bad request — invalid request payload (InvalidRequest)

    Not found — user does not exist (NotFound)

    Gone — expired refresh token (TokenExpired)

    Internal server error (InternalServerError)

    POST /auth/reset

    Reset user password.

    Request

    Body (application/json)

    username string required
    User name
    session string required
    Session token
    newPassword string required
    New password

    Responses

    No content — password reset

    Bad request — invalid request payload (InvalidRequest)

    Not found — user does not exist (NotFound)

    Gone — expired verification code or session token (TokenExpired)

    Internal server error (InternalServerError)

    POST /product/{pid}/image

    Upload product image with mask and homography for normalization.

    Request

    Headers

    Authorization string required
    Bearer JWT access token

    Path Parameters

    pid string required
    Product ID (UUID)

    Body (multipart/form-data)

    image binary required
    JPEG image data
    mask string required
    boolean mask matrix (Base64)
    hom string required
    float32[3×3] homography matrix (Base64)

    Responses

    Created — image created

    Body (application/json)

    id string required
    Image ID (UUID)
    url string required
    Presigned URL for normalized image (PNG)

    Bad request — invalid image data or homography (InvalidImageFormat, InvalidHomography)

    Unauthorized — missing or invalid Authorization header (Unauthorized)

    Forbidden — insufficient permissions (Forbidden)

    Not found — product does not exist (NotFound)

    Internal server error (InternalServerError)
