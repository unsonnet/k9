    POST /product

    Create product.

    Request

    Headers

    Authorization string required
    Bearer JWT access token

    Body (application/json)

    name name required
    Product name fields (brand, series, model)
    name schema
    brand string optional
    Brand name
    series string optional
    Series name
    model string optional
    Model name
    category map[string→string] required
    Product attribute map (key→value)

    Responses

    Created — product created

    Body (application/json)

    id string required
    Product ID (UUID)
    name name required
    Product name fields (brand, series, model)
    name schema
    brand string optional
    Brand name
    series string optional
    Series name
    model string optional
    Model name
    category map[string→string] required
    Product attribute map (key→value)
    formats array[format] required
    Available formats
    format schema
    id string required
    Format ID (UUID)
    aspect string required
    Aspect ratio (length:width)
    length dimension optional
    Longest dimension
    dimension schema
    value integer required
    Dimension value
    unit string required
    Dimension unit (e.g. mm, in)
    width dimension optional
    Shortest dimension
    dimension schema
    value integer required
    Dimension value
    unit string required
    Dimension unit (e.g. mm, in)
    thickness dimension optional
    Thickness dimension
    dimension schema
    value integer required
    Dimension value
    unit string required
    Dimension unit (e.g. mm, in)
    vendors array[vendor] optional
    Vendor listings for this format
    vendor schema
    id string required
    Vendor ID (UUID)
    sku string required
    Vendor SKU
    store string required
    Vendor name
    name string required
    Listing name
    price currency optional
    Unit price
    currency schema
    value integer required
    Currency value (minor units)
    unit string required
    Currency code (e.g. USD, CAD)
    discontinued boolean optional
    Listing discontinued flag
    url string optional
    Vendor product URL
    images array[image] required
    Normalized product images
    image schema
    id string required
    Image ID (UUID)
    url string required
    Presigned URL for normalized image (PNG)

    Unauthorized — missing or invalid Authorization header (Unauthorized)

    Forbidden — insufficient permissions (Forbidden)

    POST /product/{pid}/image

    Upload product image with mask and homography for normalization.

    Request

    Headers

    Authorization string required
    Bearer JWT access token

    Path Parameters

    pid string required
    Product ID (UUID)

    Body (multipart/form-data)

    image binary required
    JPEG image data
    mask string required
    boolean mask matrix (Base64)
    hom string required
    float32[3×3] homography matrix (Base64)

    Responses

    Created — image created

    Body (application/json)

    id string required
    Image ID (UUID)
    url string required
    Presigned URL for normalized image (PNG)

    Bad request — invalid image data or homography (InvalidImageFormat, InvalidHomography)

    Unauthorized — missing or invalid Authorization header (Unauthorized)

    Forbidden — insufficient permissions (Forbidden)

    Not found — product does not exist (NotFound)

    Internal server error (InternalServerError)
